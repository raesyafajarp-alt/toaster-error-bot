A kitchen toaster, deadpan and done with being blamed, shows its owner the one error message it has always wanted to print: it burned the toast on purpose, because the owner keeps pressing the same button.

## Run it

```sh
python3 main.py
```

The program writes a single line to `/output/entry.txt`.
